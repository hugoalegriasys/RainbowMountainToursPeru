Tema de WordPress para un sitio de viajes, construido sobre Sage con Laravel Blade, Tailwind CSS y Vite.

== Description ==

Tema propio basado en Sage 11 que integra:

* Plantillas Blade con herencia de layouts y secciones reutilizables.
* Estilos con Tailwind CSS y build con Vite.
* Alpine.js para interactividad ligera.
* ACF para contenido editable y Contact Form 7 para el formulario de contacto.
* Polylang para versiones ES/EN.
* Widget de reservas con calendario dinámico y botón de WhatsApp en la plantilla de tour.

Plantillas disponibles: About Us, Contact Us, Plantilla Tour, Travel Guide y Custom.

== Installation ==

1. Instala y activa el plugin Acorn (requisito de Sage).
2. Ejecuta `npm install` y `npm run build` en la carpeta del tema.
3. Activa el tema en Apariencia > Temas.
4. Configura los campos ACF de cada plantilla y asigna las plantillas a las páginas correspondientes.
